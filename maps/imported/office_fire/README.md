# 室内办公室火灾骨架

本地图根据用户提供的平面草图与室内视频重新搭建。参考资料保存在 artifacts/indoor-fire-20261012/reference。四个矩形房间和门的位置来自草图；18 × 16 米尺寸为保证机器人通行而推定，并非视频测量结果。

机器人出生于 (0, -6.7)，朝向 +Y。正前方左侧为大房间，右侧有近端、中部两个小房间，右前方还有一个小房间。出生点左侧设置三排、每排两套带电脑的公司工位。外墙和天花板封闭整个室内空间，墙高 2.8 米。

四扇门净开口为 1.25 米，门高 2.15 米，初始关闭，使用真实侧铰链向房间内开启。图中的斜线被解释为门符号，而非始终敞开的门扇姿态。connects 描述开门后潜在连通性，运行时须读取真实门状态。静态地图保留门洞；关闭门扇由激光雷达与 Nav2 障碍层感知。

导航语义区域只把实际空旷的大厅分为入口、工位旁、主通道和横向通道。两条绕行路径在大厅内形成真实环路，四个封闭房间各有且仅有一处门洞。六套固定工位的占地同时写入静态导航栅格，避免规划路线穿过桌椅。

几何、材质和火焰/烟雾效果由项目代码制作；用户资料仅作视觉参考。火灾效果为视觉模拟，不提供温度、燃烧传播或烟气流场计算。
