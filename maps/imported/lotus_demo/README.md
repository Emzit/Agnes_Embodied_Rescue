# 莲华古城静态演示骨架
文件：lotus_skeleton.json。支持 Agnes 现有上传/预览 schema。
这是非官方、自绘的 A/B/C 三点拓扑示意，不是游戏精确地图、最新补丁复刻或测绘数据；尺度与区域矩形仅用于演示。
包含 24 个静态语义区域、两处旋转门位置标注、A/B 可破坏连接墙标注。条件连接只是潜在拓扑，实际可通行性未知。
参考：https://playvalorant.com/en-gb/news/dev/lotus-unearthing-valorant-s-lost-city/
不含 Riot 游戏模型、纹理或提取资源。名称权利归原作者。
## 演示
打开 http://127.0.0.1:4177/demo → 骨架上传 / 预览。
可下载到 Windows 后选 JSON 上传，也可点“预览莲华示例”。
必须显示 STATIC PREVIEW / NOT_ACTIVATED。不会切换 ROS /map、Gazebo 场景或 Agent 当前世界注册表。
## 范围限制
仅验证 JSON/schema/静态展示。旋转门、破坏墙、楼层高差、碰撞和导航均未实现或验收。
后续若要让机器人真正进入莲华场景，需要另行建模、物理激活和安全验收，不能用此预览冒充实景换图。

## 紧凑平面尺寸
当前演示骨架的平面坐标、墙厚和门洞宽度统一为原始尺寸的 50%，地图边界为 24 × 20 米（原为 48 × 40 米）。拓扑、墙高、机器人尺寸及朝向保持原值；起点、语义区域和交互点均使用缩放后的同一份骨架编译生成。

为满足现有机器人通行要求，Defender_Route 的宽度由缩放后的 1 米微调为 1.1 米，并同步相邻墙体及区域边界。其余平面尺寸按 50% 缩放；地图面积约为原来的 25%。
